# 套件对照表维护说明

此文件供维护者使用，不作为文档页面发布。

## 页面地址

- 固定路径：`/docs/stm32/getting-started/kit-checklist`
- 页面通过 `index.mdx` 中的 `slug` 固定地址。包装二维码印制后，请保持该地址可访问。
- 印制前应完成实际清单、部署页面，并用手机扫码检查最终线上地址。

## 待补充内容

仅一个套餐，页面已按提供的装箱清单录入 13 项物品及数量。

1. 填写每件物品的详细参数规格，保留已确认的线长、颜色和马达组件内容。
2. 补充每件物品的识别要点、用途和已核实的教程链接。
3. 按下表补充照片，替换页面中对应编号的图片占位。
4. 完成后移除剩余占位内容。

## 卡片编辑方法

在 index.mdx 中，每个 KitItem 对应一件物品：
- name：物品名称。
- quantity：应有数量。
- specs：规格。
- usage：用途说明，可填写 JSX 链接。
- number：图片编号，与补图清单一致。

补图后，在对应 KitItem 内增加一行（先确保图片文件存在）：
image={require('./img/stm32-board.png').default}

未设置 image 时自动显示图片占位。手机上图文上下排列，600px 及以上左右排列。
