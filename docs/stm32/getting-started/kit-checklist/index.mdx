## 发现缺件或无法识别的物品

请通过购买订单联系店铺客服，并提供：

- 订单中的套餐名称。
- 收到的全部物品平铺照片。
- 缺少或无法识别的物品名称；无法确认名称时，提供正反面和接口近照。
- 实际收到的数量，以及包装是否破损。
