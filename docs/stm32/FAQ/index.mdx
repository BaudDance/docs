## 点下载时，弹窗问 Proceed 还是 Cancel

<div style={{ display: "flex", justifyContent: "left", alignItems: "center", marginBottom: "20px", marginBottom: "20px"}}>
<img src={require('./img/intro/报错编译失败.png').default} alt="noTitle" width="600px" style={{boxShadow: "0px 0px 8PX 5PX rgba(0, 0, 0, 0.1), inset 0 0 50px rgba(0, 0, 0, 0.3)"}}/>
</div>

这个报错是因为编写的代码中存在语法错误，这样没办法编译成可执行文件。

解决掉代码中的语法错误，即可正常下载。
